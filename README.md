## Descripción del Ejercicio
Implementación de la clase `Empleado` que gestiona información personal y salarios mensuales con validación defensiva (solo valores positivos). La clase de prueba `PruebaEmpleado` instancia dos objetos, calcula sus salarios anuales y aplica un incremento del 10%.
